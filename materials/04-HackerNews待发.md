Author here. I write long Chinese Markdown in Typora for hours/day.

Most themes look fine for short notes; for dense CJK text the line height and measure feel like chat bubbles. I locked three metrics first (1rem body, 1.65 leading, 52em measure), then generated CSS from tokens so I never hand-edit 3000 lines.

Free tier (MIT): Hekouwang / Hekouwang Dark — warm paper card on #write.
Paid pack adds 6 more skins (same metrics, different palettes) — details on the landing page, not in the repo.

Compared to Typora Gallery's Claude Theme (independent work, not a fork): they ship ~24MB fonts + 397 !important rules; this build enforces 0 !important and ~100KB Inter subset. Chinese uses system UI sans, not bundled serif.

Install: clone → ./scripts/install.sh → quit Typora fully (Cmd+Q) → reopen.

Happy to answer Typora-specific quirks (theme reload, font probing, dark sidebar sampling).
