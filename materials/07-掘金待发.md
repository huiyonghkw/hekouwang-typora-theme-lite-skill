## 沸点（短帖 · 推荐先发）

**标题：** 写了套 Typora 主题，专门给中文长文用的

**正文：**

盯 Markdown 一天的人应该懂：很多主题截图好看，中文一长行高就绷。

我把阅读指标钉死了：1rem / 1.65 / 52em，纸感画在编辑区。CSS 是 token 生成的，构建强制 0 个 !important，字体包 ~100KB。

免费 MIT：Hekouwang / Hekouwang Dark
仓库：https://github.com/huiyonghkw/hekouwang-typora-theme-lite-skill
体验站：https://huiyonghkw.github.io/hekouwang-typora-theme-lite-skill/

装完记得 Cmd+Q 完全退出 Typora 再开，不然改了 CSS 看起来没变化。
