## 05 作品介绍（≥30 字，≤2000 字）

> hekouwang 是一套为中文长文设计的 Typora 主题。免费 V2 提供浅色与深色两套，MIT 许可，装进 Typora 后菜单里显示为 Hekouwang / Hekouwang Dark。
>
> **要解决的问题**：中文长文在编辑器里最常见的三种疲劳——行高偏紧、行宽随窗口乱跑、行内代码和表格把行距顶开。多数主题靠装饰解决"好看"，但连读十几页时，起作用的是节奏是否统一。
>
> **做法**：先把三项阅读指标钉死，正文 1rem、行高 1.65、阅读列从 48rem 随窗口扩到 96rem；纸面比阅读列再多留 6rem 给代码和宽表格。窗口超过 1800px 时行高放宽到 1.78、段距到 1rem，否则一行九十字会读成扫视。所有块——标题、引用、列表、代码、表格——共享这套指标，靠字号、字重和留白分层，不用彩色竖条和卡片堆叠。
>
> **细节**：中英混排只随包约 100KB 的 Inter 拉丁子集，中文 fallback 到系统字体，不打包中文字体，既避开授权边界也不用下载 20MB 字库；3 列以内的小表最宽 48rem 并左对齐正文，4—9 列填满阅读列，10 列以上挂到技术画布且只留横线；Windows 上通过 body.os-windows 切到微软雅黑 UI / Cascadia Mono 字栈并保留 ClearType；侧栏收起时纸边、gutter 与投影一起消失，白纸铺满内容区。
>
> **工程约束**：CSS 不是手写的，由 scripts/tokens.json 经构建脚本生成，改配色只改 token；构建强制零 !important，并且逐套跑 WCAG 对比度审计，正文不到 4.5:1 直接构建失败。
>
> **怎么体验**：打开体验链接就是这套 CSS 的真实渲染——顶部可切换浅色/深色、正文字号（15—18px）与阅读列宽（44—96rem），也可以收起侧栏看全幅纸面；页面没有针对演示做的样式补丁，看到的就是装进 Typora 的同一份文件。安装只需 clone 仓库后运行 scripts/install.sh（Windows 用 install-windows.ps1），完全退出 Typora 再打开即可。
