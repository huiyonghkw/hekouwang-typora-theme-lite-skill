# hekouwang Typora 付费包 · 安装操作说明（v1.1.0）

> 仅随付费 zip **私发**。本目录在仓库 `dist/` 下（`.gitignore` 已忽略），**不会进公开免费仓**。

## 发给买家时带什么

1. `hekouwang-typora-theme-pack-v1.1.0-YYYYMMDD.zip`（主题包）
2. `安装操作说明.png`（本长图，微信可直接发）
3. 可选：本 `操作说明.md` 文本版

桌面交付夹副本：`~/Desktop/hekouwang-typora-买家交付-v1.1.0/`

## 安装步骤（摘要）

1. 确认 zip 能解压（损坏则重发，勿用微信压缩图传大文件）
2. 未装免费 V2 → clone 公开仓跑 `./scripts/install.sh`
3. 解压付费包 → `./unlock.sh`（或公开仓 `./scripts/unlock.sh 路径.zip`）
4. **Cmd+Q** 退出 Typora 再开 → 主题菜单选 Hekouwang V1…V6
