1确认你收到的文件

文件名类似：

hekouwang-typora-theme-pack-v1.1.0-20260806.zip

解压后应看到：

  • unlock.sh（安装脚本）
  • theme/ 里 10 个 .css
  • LICENSE-PRO.txt、VERSION、README.txt
⚠️ 若 zip 打不开或提示损坏：多半是微信压缩传输截断。请让卖家重新发，或改用「文件传输助手 / 网盘」再下一次。

2还没装免费版？先装 V2

付费包只追加 V1 / V3–V6。免费的 Hekouwang / Hekouwang Dark（V2）走公开仓：

git clone https://github.com/huiyonghkw/hekouwang-typora-theme.git
cd hekouwang-typora-theme
./scripts/install.sh

已装过免费版可跳过本步。

3安装付费包（二选一）

方式 A · 推荐：解压后在包目录执行

cd ~/Downloads/hekouwang-typora-theme-pack-v1.1.0-20260806
chmod +x ./unlock.sh
./unlock.sh

方式 B：在公开仓目录里把 zip 丢给脚本

cd ~/path/to/hekouwang-typora-theme
./scripts/unlock.sh ~/Downloads/hekouwang-typora-theme-pack-v1.1.0-20260806.zip
✅ 成功时终端会列出 10 个 CSS 已安装到 Typora 主题目录。

4完全退出 Typora 再打开

  1. 按 Cmd + Q 退出（点红点不够，必须完全退出）
  2. 重新打开 Typora
  3. 菜单 主题 / Themes → 选 Hekouwang V1 … V6（或对应 Dark）

主题目录（macOS）：

~/Library/Application Support/abnerworks.Typora/themes/

5装好后菜单里应有这些

  • ☐ Hekouwang / Hekouwang Dark（免费 V2，需先 install）
  • ☐ Hekouwang V1 / V1 Dark（科技）
  • ☐ Hekouwang V3 / V3 Dark（财经）
  • ☐ Hekouwang V4 / V4 Dark（玻璃）
  • ☐ Hekouwang V5 / V5 Dark（紫 HUD）
  • ☐ Hekouwang V6 / V6 Dark（焰彩）

六套共用阅读指标：正文 1rem · 行高 1.65 · 行宽 52em · 纸感卡片。差在配色气质。

常见问题

Q. 菜单里没有 V1–V6？
先确认 unlock 无报错；再 Cmd+Q 重开。主题目录里应能看到 hekouwang-v1.css 等文件。

Q. 只有 Dark / 只有浅色？
10 个文件应成对出现。重新跑一次 unlock；旧文件会自动备份到 .hekouwang-backups/。

Q. Windows / Linux？
本包按 macOS Typora 路径验收。其他系统请打开 Typora「打开主题文件夹」后，手动把 theme/*.css 拷进去，再重启。

Q. 能否发给别人？
不能。见包内 LICENSE-PRO.txt：个人使用，禁止二次分发。
