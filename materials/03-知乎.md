## 正文（约 1800 字 · 无价格 · 第一人称）

我一天要在 Typora 里盯 Markdown 好几个小时。公众号、笔记、技术稿都在里面写。

以前觉得主题「看着干净」就行。直到某次改长文，从下午写到晚上，眼睛酸得对不上焦，才发现行高和行宽是按西文习惯调的，中文一长就像扫弹幕。

### 让我动手的那一下

我试过很多 Gallery 主题，也下过那款很火的 Claude Theme。方向都对，但我对照公开仓库数了几项硬指标：手写 3158 行、397 处 `!important`、字体包约 24MB（含 Noto 宋体）。我自己改两行 CSS，下次升级就被覆盖，或者 Typora 偏好里的字号调节失效。

还有一类失败是不报错的：改完 CSS 看起来「没变化」。原因是 Typora 切换主题不会重载已打开的文件样式，必须 Cmd+Q 完全退出再开。我在 Chrome headless 里验全绿，Typora 里照样不对，最后只能在 Typora 里肉眼验收。

### 所以我先钉指标，再谈好看

我把三项阅读指标写进配置文件，浅色深色共用：

- 正文 `1rem`
- 行高 `1.65`（汉字密，1.5 对我来说偏紧）
- 行宽 `52em`（流体：`min(52em, calc(100% − gutter))`）

颜色再漂亮，行距不对，长文还是会累。纸感画在 `#write` 上：暖径向、大圆角、外阴影；侧栏和顶栏更深一档。层级靠字重和间距，不靠左边彩色竖条。

### 和 Gallery Claude Theme 的差别（数字对照）

| | Gallery Claude Theme | hekouwang（我的） |
|---|---|---|
| 写法 | 手写 | token 生成 |
| `!important` | 397 处 | 0（构建强制） |
| 字体包 | ~24MB | ~100KB Inter latin |
| 正文中文 | Noto Serif SC（宋） | 系统无衬线 |
| 界面 | 主要编辑区 | 侧栏 / 大纲 / 搜索 / 专注模式 |

独立实现，不是 fork。Anthropic Sans 我实测过字符覆盖：581 个字符里 CJK 汉字 0 个，连中文标点都没有，打包宋体是错方向。

### 免费 / 付费怎么分

公开仓 MIT：**Hekouwang / Hekouwang Dark**（暖米白编辑风），一条 install 脚本。另有六套付费皮肤（科技 / 财经 / 玻璃 / 紫青 / 焰彩），同一套阅读指标换气质，完整分档见体验站，这里不标价。

仓库里还带主题工程 Skill，clone 打开项目就能用，改配色、采样、字体探针不用另装（别把它当卖点，当维护工具就行）。

### 安装

```
git clone https://github.com/huiyonghkw/hekouwang-typora-theme-lite-skill.git
cd hekouwang-typora-theme-lite-skill && ./scripts/install.sh
```

完全退出 Typora 再开，主题菜单选 Hekouwang。

体验站：https://huiyonghkw.github.io/hekouwang-typora-theme-lite-skill/

有人真的按「改 tokens → build → install → 重启」走一遍，我想听哪里还卡。
