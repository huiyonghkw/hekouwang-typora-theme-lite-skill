## 描述（短）

Fixed reading metrics (1rem / 1.65 / 52em), token-generated CSS with zero !important, ~100KB fonts. Free MIT warm paper theme; optional paid skin pack.

## Maker's first comment

```
Hey PH — I built this because I live in Typora 4+ hours/day writing Chinese long-form.

Most themes optimize for "looks clean" in screenshots, not for dense CJK paragraphs. I locked body size, leading, and measure first, then built skins on top via tokens (no hand-editing 3k lines of CSS).

Free: Hekouwang / Hekouwang Dark (MIT, install script included)
Gallery comparison vs Claude Theme: 0 !important vs 397, ~100KB fonts vs ~24MB

macOS-tested. Would love feedback on readability after a 2-hour writing session.
```
