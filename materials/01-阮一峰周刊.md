## 正文（issue body）

项目地址：https://github.com/huiyonghkw/hekouwang-typora-theme-skill

体验站：https://huiyonghkw.github.io/hekouwang-typora-theme-skill/

我一天要在 Typora 里盯 Markdown 好几个小时。Gallery 上不少主题看着干净，中文一长就像聊天气泡：行高偏紧、行宽乱跑，盯两三个小时就累。

所以做了 **hekouwang**：先钉死三项阅读指标（正文 `1rem`、行高 `1.65`、行宽 `52em`），再在这套指标上换皮肤。免费档 MIT，菜单里叫 **Hekouwang / Hekouwang Dark**（暖米白纸感）；另有六套付费皮肤（科技 / 财经 / 玻璃 / 紫青 / 焰彩），同一指标换气质，细节写在体验站。

<img src="https://raw.githubusercontent.com/huiyonghkw/hekouwang-typora-theme-skill/main/docs/screenshot-zh.png" width="720" alt="中文长文验收样张">

和 Gallery 里已有的 [Claude Theme](https://theme.typora.io/theme/Claude-Theme/) 目标相近，但是独立实现。我对照过公开仓库：对方手写三千多行、397 处 `!important`、字体包约 24MB（含 Noto 宋体）；我这边用 token 生成 CSS、构建强制 **0 个 `!important`**、随包字体约 **100KB**（Inter latin），中文走系统无衬线。

## 功能

- **阅读指标固定**：`1rem` · `1.65` · `52em` · 纸感画在 `#write` 上；浅/深共用指标，深色只改色值
- **token 驱动**：改 `scripts/tokens.json` → `python3 scripts/build.py` → 安装；手改 CSS 下次构建会被覆盖
- **中英混排**：Anthropic Sans 实测 581 字符、CJK 0 个；不打包中文字体，西文 Inter 可变字重 300–800
- **主题工程 Skill 随仓**：clone 后 Claude Code / Cursor 可直接加载，改配色、采样、字体探针不用另装
- **免费 MIT 可 Gallery 安装**；付费包另售六套皮肤（¥9.9），色板不进公开仓

```bash
git clone https://github.com/huiyonghkw/hekouwang-typora-theme-skill.git
cd hekouwang-typora-theme-skill && ./scripts/install.sh
# 完全退出 Typora（Cmd+Q）再开，主题菜单选 Hekouwang
```
