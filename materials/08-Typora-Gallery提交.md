# 08 · Typora 官方 Gallery · 提交

- **入口：** https://theme.typora.io/
- **机制：** 提交主题 zip / 关联 GitHub，审核后上架
- **价值：** Typora 用户搜主题的第一站，免费 V2 档最适合进 Gallery

## 提交物

公开仓已含免费档：

- `theme/hekouwang.css`
- `theme/hekouwang-dark.css`
- `theme/hekouwang/`（字体目录）

## 建议填写的描述（英文 · Gallery 惯例）

**Name:** Hekouwang

**Description:**

Reading-first Typora theme for long Chinese sessions. Fixed metrics: 1rem body, 1.65 leading, 52em measure. Paper card on `#write`, full UI chrome (sidebar, outline, search). Token-generated CSS, zero `!important`, ~100KB Inter subset. Light + dark pair.

**Author:** huiyonghkw

**Repo:** https://github.com/huiyonghkw/hekouwang-typora-theme-skill

**Screenshot:** use `docs/screenshot-window.png` (shows full window)
