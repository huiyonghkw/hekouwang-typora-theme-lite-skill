hekouwang：给中文长文一套固定的阅读指标

先把正文 1rem、行高 1.65、阅读列宽钉死，再在这套指标上换皮肤。

这一页不是截图，也不是复刻样式：它直接加载仓库里 theme/hekouwang.css 的构建产物，用 Typora 同款的 #write 结构渲染。你在上面切换的每一个开关，改的都是这份 CSS 自己的变量。

它想解决的问题很具体：中文长文读两小时不累。行高偏紧、行宽乱跑、行内代码把行距顶开——单看一条都不致命，连读十几页就是疲劳。

一、为什么只修三项指标

主题最容易做的事是加装饰，最难的事是让所有块共享同一套节奏。所以先把三件事钉死，其余都在这套节奏里做加减。

正文与阅读列

正文 1rem，行高 1.65，段距 0.85rem；阅读列从 48rem 随窗口扩到 96rem，纸面再额外留 6rem 给代码和宽表格。窗口超过 1800px 时，行高放宽到 1.78、段距到 1rem——否则一行九十字会读成扫视。

中英混排

西文走随包的 Inter 可变字重（约 100KB，只含拉丁），中文 fallback 到系统字体。不打包中文字体，既避开授权边界，也不用下载 20MB 字库。数字按比例对齐：2026 年、1,247 次、99.8%。

二、行内样式一次过

加粗看字重是不是真的、斜体、删除线、行内代码、一个链接，以及 高亮。行内代码只换字色和底色，不改变行高——长段落里夹十个术语也不会把行撑开。

引用块刻意不用品牌色竖条，也不铺沉底。边界来自一条浅灰竖线，字色降一档，金句自己会浮出来。

嵌套引用继续保持缩进，但不叠加更重的视觉。

三、列表与任务

无序列表的 marker 要够淡，序号要等宽，多位数不跳位：

  • 第一项，看 marker 是否够淡
  • 第二项，带 行内代码 看行高有没有被顶开
  • 第三项，带加粗引导语：后面跟说明文字
    • 嵌套一层
    • 再来一条，含 npm run build
  1. 序号用等宽数字
  2. 第二条看段距
  3. 第三条对齐仍稳定

  • 已完成项：文字淡化，不加删除线

  • 未完成项：只有细边框

四、代码块

代码块 0.9375rem，比正文小一档，改用等宽字体；圆角与正文一致，边框只留发丝线。

/* 用户级覆盖：写在主题目录的 hekouwang.user.css 里 */
:root {
  --hk-reading-measure: 40rem;  /* 约 40 字宽的中文阅读列 */
}

#write h2 {
  font-size: 1.45rem;
  letter-spacing: -0.01em;
}

五、表格

三列以内的小表最多 48rem，左对齐正文，不拉成一张大网；四列以上填满阅读列。

数据表则按列数分配画布，不放任横向滚动把表头甩出屏幕。

六、分隔与脚注

本页就是主题 CSS 的真渲染。左侧可切换其它演示文稿；需要看实机窗，请回落地页预览区。

构建时逐套检查文字与控件的颜色对比度[1]，低于 AA 直接让构建失败——这是仓库里唯一不接受「看着还行」的地方。

  1. 对比度按 WCAG 2.1 计算，正文 4.5:1、大字 3:1；审计脚本为 scripts/contrast_check.py。 ↩

安装说明

两分钟把免费 V2 装进 Typora。改 CSS 后必须完全退出再重开，主题菜单才会加载新文件。

macOS

git clone https://github.com/huiyonghkw/hekouwang-typora-theme-lite-skill.git
cd hekouwang-typora-theme-lite-skill
./scripts/install.sh

Windows

git clone https://github.com/huiyonghkw/hekouwang-typora-theme-lite-skill.git
cd hekouwang-typora-theme-lite-skill
.\scripts\install-windows.ps1

若策略拦住脚本：powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1（只影响本次进程）。自定义主题目录用 -ThemeDir。

装完之后

  1. 完全退出 Typora（不是只关窗口）
  2. 重开后，主题菜单选 Hekouwang 或 Hekouwang Dark
  3. 也可手动复制 theme/hekouwang.css、theme/hekouwang-dark.css 与 theme/hekouwang/ 到主题文件夹

可选：更窄阅读列

在主题目录新建 hekouwang.user.css（深色用 hekouwang-dark.user.css）：

:root {
  --hk-reading-measure: 40rem;
}

版本对比

免费版是完整长文主题；专业版换的是六套独立视觉，阅读指标相同。

专业版视觉方向

  • V1 · 石墨青绿 — 冷蓝灰、薄荷青、紫链
  • V2 Pro · 典藏编辑 — 胡桃墨、古铜、暖纸（≠ 免费 V2）
  • V3 · 财经 — 海军蓝与黄铜
  • V4 · 玻璃 — 冰蓝、雾面叠片
  • V5 · HUD — 紫晶外壳、青色信号
  • V6 · 焰彩 — 李紫、珊瑚橙与粉

实机对比见落地页预览。
